# Mobile card visual test

Open `tests/mobile-card-fixture.html` through a local web server.

Recommended viewport widths:

- 320 px
- 375 px
- 390 px
- 430 px

At the bottom of the page, `overflow` must be `false` and `offenders` should be
an empty array. The fixture includes deliberately long Korean, English and
Chinese names, a Wedding Day card and a long transport route.
